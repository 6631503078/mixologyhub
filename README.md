# MixologyHub

MixologyHub is a mobile application designed for beverage enthusiasts to discover, create, and share their favorite drink recipes. Whether you're a coffee connoisseur, smoothie lover, or cocktail enthusiast, MixologyHub provides a platform to explore and create amazing beverage recipes.

## Features

- **User Authentication**
  - Secure login and registration
  - Profile management
  - Password reset functionality

- **Recipe Management**
  - Create and edit recipes
  - Categorize recipes (Coffee, Smoothies, Juice, Alcohol, Other)
  - Detailed recipe viewing
  - Personal recipe collection

- **Recipe Components**
  - Title and category
  - Ingredients with measurements
  - Step-by-step instructions
  - Custom units support

- **User Interface**
  - Modern and intuitive design
  - Category-based browsing
  - Beautiful gradient-based UI
  - Responsive layout

## Installation Guide

### For Android Users

1. ดาวน์โหลดไฟล์ .apk
   - Download the latest MixologyHub APK file from our releases
   - Make sure to download from trusted sources only

2. เปิดในอุปกรณ์ Android
   - Locate the downloaded APK file
   - Ensure your device allows installation from unknown sources
   - Go to Settings > Security > Enable "Install unknown apps"

3. ติดตั้งผ่าน File Manager
   - Open your File Manager
   - Navigate to the downloaded APK file
   - Tap on the APK file to begin installation
   - Follow the on-screen instructions
   - Wait for the installation to complete

### For Developers

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/mixologyhub.git
   cd mixologyhub
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure Firebase:
   - Create a new Firebase project
   - Add your Firebase configuration to `services/firebase.js`
   - Enable Authentication and Firestore in Firebase Console

4. Run the application:
   ```bash
   npm start
   ```
